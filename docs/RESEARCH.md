# Исследование взаимодействий · 7 ноября 2026

Исследовались публичные официальные описания поведения, а не исходники и не платные аккаунты конкурентов. Это ориентиры взаимодействий, не сравнение всех приложений и не заявление «взято объективно лучшее». Логотипы, иллюстрации и компоненты конкурентов не скопированы.

| Источник | Подтверждённый подход | Адаптация в MAQSAT |
|---|---|---|
| [Todoist: длительность задачи](https://www.todoist.com/help/todoist/features/set-a-task-duration-L1kYkZv8d) | Длительность можно менять нижним краем блока календаря; добавление из временного слота. | Собственная временная сетка, перенос и изменение длительности, подтверждение сервером, откат ошибки. |
| [TickTick: Focus](https://help.ticktick.com/articles/7055782010496745472) | Таймер Pomodoro и секундомер. | Четыре метода, общий таймер вне отдельных страниц, журнал и повтор отправки без дубля. |
| [Hevy: workouts vs routines](https://help.hevyapp.com/hc/en-us/articles/33703513582871-Workouts-vs-Routines-in-Hevy-What-They-Mean-and-How-to-Use-Them) | Запись конкретного занятия отделена от повторно используемого шаблона. | Таблица тренировки, независимый снимок шаблона, связанные события календаря без переписывания истории. |
| [MDN: Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API/Using_the_Notifications_API) | Уведомления требуют разрешения и зависят от поддержки платформы. | Явное разрешение в настройках и внутрисайтовое напоминание как запасной вариант. |
| [MDN: Push API](https://developer.mozilla.org/en-US/docs/Web/API/Push_API) | Фоновая доставка требует отдельной инфраструктуры Push/Service Worker. | Не выдаём polling открытой вкладки за push при закрытом сайте. Эта инфраструктура пока не добавлена. |

Собственные решения: приоритет названия/даты регулярного платежа; пользовательские сферы в задачах; доступность всех функций без подписок; нейтральные привычки без наказаний за пропуски; сохранение исторических тренировок при удалении календарного плана.

Автоматического мониторинга конкурентов по расписанию не настроено. В приложении добавлена только ручная техническая диагностика базы и endpoint `/healthz` для подключения отдельного внешнего мониторинга.

Для Windows и минимальных контейнеров добавлен пакет `tzdata`: [официальная документация Python zoneinfo](https://docs.python.org/3/library/zoneinfo.html) рекомендует явную зависимость для систем без IANA-базы часовых поясов.
