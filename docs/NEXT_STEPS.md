# MAQSAT — следующее после MVP

1. **Релизное качество:** установить npm-пакеты, собрать frontend, проверить React-приложение в Chromium и на мобильной ширине, добавить UI e2e-тесты (Playwright).
2. **PostgreSQL:** прогнать миграции на отдельной тестовой БД, тестировать конкурентное подтверждение повторяющихся платежей.
3. **Безопасность:** централизованный rate-limiter, восстановление пароля, подтверждение контакта, audit logs, регулярные резервные копии, privacy policy, экспорт и удаление данных.
4. **Календарь:** повторяющиеся правила, исключения, связанные задачи и блоки времени, синхронизация с внешними календарями по запросу.
5. **Цели / Life Map:** связь задач и проектов с целями, автоматический обоснованный прогресс, этапы.
6. **Здоровье:** шаблоны тренировок, подходы/упражнения, заметки о питании и сне, доступные по желанию пользователя, без обязательных калорийных лимитов.
7. **UX:** drag-and-drop, уведомления, подтверждение удалений с Undo, командная панель, accessibility audit.
8. **Мобильное будущее:** PWA, позже при необходимости отдельный мобильный клиент.
