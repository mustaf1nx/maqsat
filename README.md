# MAQSAT · Daily Flow · 0.3.0

Бесплатное личное веб-приложение: задачи, расписание, идеи, цели, деньги, работа, тренировки, привычки и фокус. Несколько аккаунтов с отдельными данными. Регистрации, подписок и платных ограничений нет.

**Обновление существующего проекта, а не HTML-макет.** React + TypeScript + Vite, FastAPI, SQLAlchemy/Alembic, PostgreSQL в Railway. SQLite — для локальной разработки и части тестов.

## Что реализовано

| Раздел | Возможности |
|---|---|
| Главная | Задачи действительно на сегодня, просроченные дела, события, привычки, цели, платежи и фактическая статистика. |
| Задачи | Редактор по нажатию на задачу, чек-лист, приоритет, дата, длительность, цель и проект, поиск/фильтры, отмена выполнения. |
| Расписание | День, неделя, месяц, список; создание в свободном слоте; перетаскивание и изменение длительности с шагом 15 минут в дневной/недельной сетке; отмена переноса. |
| Повторения | Каждый N-й день или каждую N-ю неделю в выбранные дни; необязательная конечная дата, часовой пояс, место, напоминание. Изменение одного занятия отдельно от серии. |
| Идеи | Редактирование, преобразование в задачу, корректный сброс связи после удаления задачи. Повторное преобразование не создаёт дубликат живой задачи. |
| Финансы | «Расход» и «Доход», месячный фильтр, категории, редактирование. У регулярного платежа выделены название и дата. Подтверждение платежа один раз за месяц, отмена подтверждения, пауза. |
| Работа | Проекты, клиенты, ставка, рабочие записи. Ожидаемый заработок отделён от реально полученных денег. |
| Цели | Ручной прогресс или расчёт по связанным задачам. |
| Тренировки | Название, дата, заметка, длительность, таблица «упражнение / подходы / повторы или время / заметка». Собственные шаблоны, план и завершённый журнал. |
| Календарь ↔ тренировки | Событие категории «Тренировка» или с распознаваемым названием «Зал» появляется в планах тренировок. На одно занятие — один журнал. Самостоятельная запись создаёт событие. Перенос события меняет дату связанного журнала. |
| Привычки | Дни недели, числовая цель и единица, частичное выполнение, история за 28 дней, редактирование прошлых отметок, серия по запланированным дням, архив. |
| Фокус | Помодоро 25/5, длинный интервал 50/10, собственные интервалы, секундомер; пауза, перерывы, журнал, сохранение состояния в браузере и идемпотентное сохранение сеанса. |
| Шаблоны | 14 встроенных заготовок и сохранение своих. Применение открывает редактор; запись не создаётся без подтверждения. |
| Быстрые действия | `Ctrl+K` / `Cmd+K`: поиск задач, идей, проектов и создание разных типов записей. |
| Настройки | Имя, часовой пояс, пароль, экспорт личных записей JSON, создание пользователей администратором, проверка доступности базы. |

Убрано «Личное пространство», переработаны типографика, контраст, поля, карточки и мобильная навигация. Светлая и тёмная темы сохраняются. Manrope запрашивается через CSS; при недоступности источника используется системный шрифт. Файлов шрифтов в архиве нет.

## Важные правила

**Напоминания:** проверка каждые 30 секунд при открытом приложении, внутри сайта и через Notification API при разрешении браузера. Нет Service Worker/Web Push, email или гарантии доставки при закрытой вкладке, спящем устройстве либо ограничениях ОС. Для критически важных событий нужен независимый надёжный канал.

**Расписание:** перенос повторяющегося блока меняет только это занятие. Для изменения цикла откройте блок → «Вся серия». Перенос мышью проверен на настольном Chromium. На телефоне доступен дневной вид и редактор; touch-drag на настоящих iOS/Android-устройствах отдельно не проверен.

**Журналы:** удаление события не уничтожает уже записанную тренировку. Удаление журнала тренировки не удаляет план из календаря. Изменение шаблона не переписывает сохранённые тренировки. Время связанного журнала меняйте через календарь.

**Деньги:** регулярные платежи не списываются автоматически. День 31 в коротком месяце означает последний день месяца. Разница доходов и расходов — не баланс банковского счёта. Нет банковской интеграции.

**Фокус:** состояние хранится по аккаунту в localStorage этого браузера. Это не синхронизация активного таймера между устройствами. Запись сеанса начинается с одной полной минуты; повтор сохранения использует один `client_id` и не дублирует запись. Перерыв не запускается автоматически. Очистка данных браузера удаляет несохранённый таймер, но не серверный журнал.

**Шаблоны:** пользовательские шаблоны сохраняются из корректно заполненной формы. Это не текст «здесь будут шаблоны». Заготовки со стоимостью требуют указать собственную сумму. Таблица тренировки не задаёт пользователю программу нагрузок.

## Локальная разработка

Нужны Python 3.12, Node.js 22 и npm.

```bash
cd backend
python -m venv .venv
# Git Bash на Windows:
source .venv/Scripts/activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m alembic upgrade head
python -m app.manage create-admin --username admin --name "Administrator"
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

В другом терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`. Локально используется `backend/maqsat_dev.db`, если `DATABASE_URL` не задана. `.env` не загружается автоматически; задайте переменные окружения терминала. Не используйте production URL для тестов.

## Проверки

```bash
cd backend
pip install pytest pytest-cov httpx
python -m pytest -q --cov=app --cov-report=term-missing
```

```bash
cd frontend
npm install
npm run typecheck
npm run test:unit
npm run build
```

Vite складывает результат в **`web_dist/` в корне проекта**, не в `frontend/dist`.

Полноценный браузерный прогон после сборки, из корня проекта:

```bash
pip install -r backend/requirements.txt pytest httpx playwright
python -m playwright install chromium
python -m pytest e2e -q
```

E2E поднимает временную SQLite-базу и API на свободном локальном порту. Демонстрационные аккаунты создаются только в этой временной базе. `.github/workflows/verify.yml` отдельно проверяет PostgreSQL 18 в одноразовой базе `maqsat_test`; эти проверки не обращаются к Railway.


## Безопасность и границы

Argon2id, серверные сессии, HttpOnly-cookie, Secure в production, CSRF/Origin-проверки и фильтрация записей по владельцу сохранены. Администратор не получает API для чтения чужих персональных записей. Проверки не являются независимым аудитом безопасности.

Лимит входов остаётся в памяти одного процесса. Нет 2FA, восстановления по email, распределённого rate limiting, нагрузочного теста или фоновой доставки уведомлений. JSON-экспорт — не резервная копия PostgreSQL и не функция обратного импорта. Диагностика в настройках — проверка по запросу, не внешний круглосуточный мониторинг.

Питание, банковские интеграции, AI и мобильное нативное приложение в это обновление не входят. Существующие функции не скрыты платными тарифами.
